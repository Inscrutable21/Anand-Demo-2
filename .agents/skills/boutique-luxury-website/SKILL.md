# Boutique Luxury Website Production Playbook

A complete, battle-tested engineering blueprint for creating high-end boutique hospitality websites (inspired by Casa Momo Graz, Aman, and Awwwards Site of the Day winners). This guide details every component, animation timeline, design token, modular build pipeline, and critical trap to avoid.

---

## 1. Architectural Overview & Philosophy

### Core Tenets
1. **Lightweight & Modular**: Zero bloated bundlers (no Webpack, Vite, or Next.js required for static sites). Uses a clean vanilla Node.js compilation pipeline (`build.js`) that concatenates HTML section partials and CSS modules into production-ready files.
2. **High-Performance Motion**: 60fps+ animations powered by **GSAP (GreenSock)** and **ScrollTrigger**, paired with **Lenis** for momentum-preserving smooth scrolling.
3. **Tactile Editorial Luxury**: High-contrast typography (`#FFF0CA` cream on `#0e1201` dark olive), editorial line heights (`1.0` to `1.15`), micro-interactions, subtle SVG fractal noise grain, and custom cursor followers.
4. **Strict Zero-Emoji Policy**: Unicode emojis degrade luxury branding. All icons are hand-crafted, clean inline SVG vectors with `stroke="currentColor"` or `fill="currentColor"`.
5. **Universal Deployment**: Synchronizes compiled assets to root, `/public`, and `/dist` to guarantee 100% zero-configuration deployment on Vercel, Netlify, or standard static hosts.

## 3. Modular Build Pipeline (`build.js`)

The build script compiles modular HTML and CSS in under 50ms without external dependencies.

```javascript
// build.js
const fs = require('fs');
const path = require('path');

function buildHTML() {
  const templatePath = path.join(__dirname, 'template.html');
  if (!fs.existsSync(templatePath)) return;

  let html = fs.readFileSync(templatePath, 'utf8');

  // Replace <!-- @include: sections/filename.html -->
  const includeRegex = /<!--\s*@include:\s*([^\s]+)\s*-->/g;
  html = html.replace(includeRegex, (match, filePath) => {
    const fullPath = path.join(__dirname, filePath);
    if (fs.existsSync(fullPath)) {
      const content = fs.readFileSync(fullPath, 'utf8').trim();
      return `<!-- BEGIN ${filePath} -->\n${content}\n<!-- END ${filePath} -->`;
    }
    return `<!-- Missing include: ${filePath} -->`;
  });

  fs.writeFileSync(path.join(__dirname, 'index.html'), html, 'utf8');
}

function buildCSS() {
  const stylesDir = path.join(__dirname, 'styles');
  const styleFiles = [
    'variables.css', 'cursor.css', 'preloader.css', 'header.css',
    'hero.css', 'philosophy.css', 'apartments.css', 'host.css',
    'feel-at-home.css', 'graz-guide.css', 'reviews.css', 'footer.css',
    'modals.css', 'book.css', 'responsive.css'
  ];

  let bundle = `/* Compiled Modular Stylesheet */\n\n`;
  styleFiles.forEach(file => {
    const filePath = path.join(stylesDir, file);
    if (fs.existsSync(filePath)) {
      bundle += `/* --- File: styles/${file} --- */\n${fs.readFileSync(filePath, 'utf8').trim()}\n\n`;
    }
  });

  fs.writeFileSync(path.join(__dirname, 'style.css'), bundle, 'utf8');
}

function syncDirectories() {
  // Mirror output to /public and /dist for universal Vercel output compatibility
  ['public', 'dist'].forEach(dirName => {
    const targetDir = path.join(__dirname, dirName);
    if (!fs.existsSync(targetDir)) fs.mkdirSync(targetDir, { recursive: true });

    ['index.html', 'book.html', 'style.css', 'script.js'].forEach(file => {
      const src = path.join(__dirname, file);
      const dest = path.join(targetDir, file);
      if (fs.existsSync(src)) fs.copyFileSync(src, dest);
    });

    const assetsSrc = path.join(__dirname, 'assets');
    const assetsDest = path.join(targetDir, 'assets');
    if (fs.existsSync(assetsSrc)) fs.cpSync(assetsSrc, assetsDest, { recursive: true });
  });
}

function buildAll() {
  buildHTML();
  buildCSS();
  syncDirectories();
}

buildAll();
```

## 4. Design Tokens & Visual Language

### Exact Color Palette
| Token | Hex Value | Usage |
| :--- | :--- | :--- |
| **Dark Olive** | `#0e1201` | Primary site background, dark cards, deep contrast |
| **Cream** | `#FFF0CA` | Primary typography, CTA buttons, active glows |
| **Terracotta Bronze** | `#BC6F45` | Accent badges, star ratings, category labels |
| **Vintage Butter Vanilla** | `#F5E6C8` | Philosophy Card 3 background, soft warm accents |
| **Olive Dark Accent** | `#161c06` / `#182006` | Frosted sticky search bar, input backgrounds |
| **Muted Cream** | `rgba(255, 240, 202, 0.65)` | Subtitles, specifications, secondary descriptions |

### Typography System
- **Display & Headings**: `font-family: 'Plus Jakarta Sans', sans-serif;` with `font-weight: 400`, `letter-spacing: -0.03em`, and tight `line-height: 1.0`.
  - Editorial Heading Scale: `font-size: clamp(3.8rem, 9.2vw, 8.5rem);`
- **Body & Captions**: `font-family: 'Plus Jakarta Sans', sans-serif;` with `font-weight: 300 to 400`, `line-height: 1.5 to 1.6`.
- **Accent Serif**: `'Cardo', Georgia, serif;` for quotes and subtle literary details.

## 6. Critical Traps, Gotchas & Anti-Patterns

### 1. The CSS `opacity: 0` ScrollTrigger Invisibility Trap
> [!CAUTION]
> **Never set `opacity: 0; transform: translateY(...)` on primary headings in CSS stylesheets.**
> If ScrollTrigger fails to calculate offsets due to pinned sections above it, or if JavaScript loads slowly, the headings remain permanently invisible to the user.
> 
> **The Fix**: Keep all headings `opacity: 1 !important; visibility: visible !important;` in CSS. Animate entrance strictly via GSAP `from()` in JavaScript:
> ```javascript
> gsap.from('.host-headline', {
>   y: 40,
>   opacity: 0,
>   duration: 1,
>   ease: 'power3.out',
>   scrollTrigger: { trigger: '.host-headline', start: 'top 85%' }
> });
> ```

### 2. Lenis Touch Momentum Conflicts on Mobile
> [!WARNING]
> Enabling `syncTouch: true` in Lenis locks Android and iOS native 120Hz momentum scrolling, causing pinned sections to jump or stutter.
> 
> **The Fix**: Initialize Lenis with `syncTouch: false`:
> ```javascript
> const lenis = new Lenis({
>   duration: 1.2,
>   easing: (t) => Math.min(1, 1.001 - Math.pow(2, -10 * t)),
>   orientation: 'vertical',
>   gestureOrientation: 'vertical',
>   smoothWheel: true,
>   syncTouch: false,
>   touchMultiplier: 1.5
> });
> ```

### 3. Vercel Static Routing & `/book` Clean URLs
> [!IMPORTANT]
> When deploying static files with subpages on Vercel:
> 1. Always enable `"cleanUrls": true` in `vercel.json`.
> 2. Include rewrites for clean paths:
>    ```json
>    {
>      "buildCommand": "node build.js",
>      "cleanUrls": true,
>      "rewrites": [
>        { "source": "/book", "destination": "/book.html" }
>      ]
>    }
>    ```
> 3. Mirror compiled artifacts (`index.html`, `book.html`, `style.css`, `script.js`, `/assets`) into both `/public` and `/dist` via `build.js` to ensure automatic entrypoint detection regardless of Vercel project settings.

### 4. Undefined Input References in Event Handlers
> [!WARNING]
> Never assume date inputs exist on every page without null checks. Always use safe fallbacks:
> ```javascript
> const defaultCheckin = new Date().toISOString().split('T')[0];
> const checkinVal = document.getElementById('heroCheckin')?.value || defaultCheckin;
> ```
